仓库 / 环境 / 文档 Tab 长什么样

三个 tab 的线框图 + 终端偏好设置。点击选择或终端回复。

Tab 1 — 仓库（gws repo add / ls / rm）
粘贴 git 地址，支持一次多个（空格分隔），内部执行 gws repo add … && 提示 sync
仓库当前分支操作
📦 order-service
git@git.example.com:group/order-service.git		main移除
📦 user-service
git@git…/user-service.git		main移除
📦 admin-webmaster移除
Tab 2 — 环境（gws env add / ls / rm + gws sync）
sync 是环境 tab 的核心动作：重置所有 envs 到远程
dev 12 个模块 · origin/dev 镜像 📂 访达 · 移除
pre 12 个模块 📂 访达 · 移除
Tab 3 — 文档（汇总 hub 下所有需求文档，gws doc ls/push/commit）
文档工作区Confluence操作
📄 技术方案.mdcheckout-revamp● 已同步上传 · 访达
📄 排期.mdcheckout-revamp○ 未上传上传 · 访达
📄 阶段二设计.mdphase2○ 未上传上传 · 访达

上传 = gws doc push（需配置 GWS_DOC_UPLOADER，未配置时按钮置灰并提示）

设置 — 终端偏好（⌘, 打开）
在终端中打开（Open in Terminal）

默认「跟随系统」：检测到 iTerm2 已安装就走 iTerm2（AppleScript），否则回退 Terminal.app。设置里可强制指定。
